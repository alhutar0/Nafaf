World cities with 10,000+ inhabitants, split into 15°×15° tiles (c_<latBand>_<lonBand>.json; band = floor((lat+90)/15), floor((lon+180)/15)).
Each row: [name, ISO country code, lat, lon, population in thousands].
Data: GeoNames (https://www.geonames.org), licensed CC BY 4.0, via the all-the-cities npm package (MIT).
